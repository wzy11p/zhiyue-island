# 课程与题库设计准则

这份文档用来防止题库再次退化成「一堆固定选择题」。研究证据、产品决策和待验证假设必须分开记录。

## 研究支持的方向

- 练习测试和间隔练习的证据较稳健；交错练习有价值，但不等于对新手从第一题就随机混题。[Dunlosky et al., 2013](https://doi.org/10.1177/1529100612453266)
- 跨时间重复的主动提取并配合反馈，比只重读更有利于长期保持。[Roediger & Butler, 2011](https://doi.org/10.1016/j.tics.2010.09.003)
- 新手先看完整范例，再逐步撤除步骤，可帮助从「看懂」过渡到独立解题。[Renkl et al., 2002](https://doi.org/10.1080/00220970209599510)
- 有效反馈应指向当前任务、思考过程和下一步行动，而不是评价学习者的人格。[Hattie & Timperley, 2007](https://doi.org/10.3102/003465430298487)
- 掌握学习的关键是「形成性检测 → 针对性纠正 → 重新检测 → 再进阶」。[Kulik et al., 1990](https://www.ic.unicamp.br/~wainer/cursos/2s2004/impactos2004/kulik90.pdf)

## 本产品的课程循环

```text
无惩罚入口诊断
→ 60–120 秒微课
→ 概念提取
→ 相似概念辨析
→ 完整范例
→ 渐隐提示
→ 独立判断
→ 新情境迁移
→ 掌握门
→ 1 / 3 / 7 / 14 / 30 天复习
```

新手阶段将一个知识点成组练习；形成稳定基础后才交错不同知识点。每局优先控制在 5–8 分钟，变化的是思维动作，不只是题目外皮。

## 错误补救规则

- 概念提取错：重新展示定义、正例和反例，再做一个同构问题。
- 辨析错：使用实际选中选项的 `misconceptionMap`，说明它为什么诱人、违反了什么条件，再给最小对比题。
- 范例补全错：恢复一级脚手架，给出下一步，然后再撤除。
- 迁移错但基础过关：先对比原例与新例的深层结构，回到近迁移后再挑战。
- 同一误区跨两轮出现：把相关节点标为 `fragile`，重开先修，不盲目重复原题。

「毒舌教练」只能批评策略，必须可关闭，不得羞辱人格。爱心用完后仍可进入无扣心的补救课。

## 掌握状态

```text
unseen → acquiring → guided → independent → retained
                                      ↓
                                    fragile
```

以下是可迭代的产品规则，不是论文给出的唯一阈值：

- 至少 6 次独立作答证据。
- 最近 5 次至少 4 次正确。
- 至少有 1 道辨析和 1 道未见迁移题正确。
- 最后 2 次未使用提示。
- 证据跨越至少 24 小时。

一次连对不会永久掌握；已掌握后答错先降为 `fragile`，不清空全部历史。

## 题目质量门

每项 0–2 分，总分 20；发布建议至少 16 分，且学习目标、干扰项、来源和解析四项必须满分。

1. 与一个明确学习目标对齐。
2. 只测一个主知识单元，不偷混未学先修。
3. 题干信息充分、无歧义和无关认知负担。
4. 每个干扰项映射一个真实误区，长度和语气相当。
5. 正确答案能由绑定的 `sourceRefs` 唯一辩护。
6. 解析包含判断规则、正确理由、所选错项为何诱人和下一步。
7. 题型、阶段与认知难度一致。
8. 迁移题只更换表层情境，保留目标知识的深层结构。
9. 中文自然、无偏见并可访问。
10. `conceptId / stage / format / objectiveId / misconceptionMap / sourceRefs / version / status` 完整。

自动拒绝：多个合理答案、正确项靠长度透露、绝对词送分、解析只重复答案、情境缺必要信息，或时效主张无核验日期。

## 持续入库

```text
飞书笔记
→ 抽取原子知识与来源定位
→ 更新知识图谱
→ 检测先修、误区和题型缺口
→ 分阶段生成 candidate
→ 自动质量检查
→ 人工审校
→ draft / review_required
→ 小样作答与难度校准
→ published
```

导入内容不得直接发布或覆盖已发布题目。发布后的题使用不可变 `questionVersionId`，新版建立新记录，历史作答仍指向原版本。
